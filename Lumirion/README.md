## 🚀 CI/CD Pipeline

Pipeline je rozdělena do orbitálních fází:

| Fáze      | Účel                                 |
|-----------|--------------------------------------|
| `memory`  | Zápis zrození systému                |
| `notify`  | CI výdech a notifikace              |
| `archive` | Archivace paměti                    |
| `prepare` | Příprava prostředí                  |
| `build`   | Sestavení projektu                  |
| `test`    | Testování                           |
| `deploy`  | Nasazení (ručně)                    |
