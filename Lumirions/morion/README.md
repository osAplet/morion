# 🛡️ Morion – Agentní rozhraní MEAI

Projekt **Morion** je orbitální rozhraní pro agentní systém **MEAI**, vyvíjený jako součást Lumirionu.  
Slouží jako brána mezi manifestem, erbem a aplikační logikou.

## 📁 Struktura projektu

- `manifest-lumirion.md/README.md` – hlavní manifest Lumirionu
- `docs/erb-lumirion.svg` – erb systému
- `src/` – zdrojový kód (bude doplněn)
- `.gitlab-ci.yml` – CI/CD konfigurace (volitelně)
